# 鼓风炉模型优化记录

## 修改日期
2026/06/28

## 修改目标
根据《天工开物》明崇祯十年刊本·冶铸卷原版插图，优化鼓风炉3D模型，使其更符合明代古籍原画风格，同时保持物理合理性。

## 主要修改内容

### 1. 炉体结构优化
- **炉底半径**: 0.7 → 0.6（缩小以匹配古籍插图）
- **炉顶半径**: 0.5 → 0.45（收口更明显）
- **炉腰半径**: 0.82 → 0.68（减小腰鼓形宽度，使炉体更细长）
- **铁箍数量**: 3道 → 2道（简化装饰元素）
- **铁箍尺寸**: 0.025 → 0.022（更精细）

### 2. 风箱设计改进
- **位置调整**: Y轴从0.9降至0.65（更低，更符合古籍插图）
- **位置调整**: X轴从1.5调整至1.3（更靠近炉体）
- **箱体尺寸**: 1.0×0.5×0.5 → 1.2×0.35×0.45（更扁平，更长）
- **活塞杆**: 更细长的设计（0.04 → 0.03半径，0.6 → 0.8长度）
- **支撑结构**: 从Z轴两根立柱改为X轴两根木腿，更符合古籍描绘
- **出风口**: 更短的锥形送风管（0.3 → 0.25长度）
- **动画调整**: 推拉幅度从0.18减小到0.15，基准位置调整

### 3. 风口风沟简化
- **主送风管**: 长度从0.8减至0.65，位置随风箱调整
- **移除**: 对称副风口（简化设计）
- **风沟尺寸**: 1.4×0.12×0.2 → 1.2×0.10×0.18（缩小比例）
- **风沟盖板**: 0.04 → 0.03厚度（更精细）

### 4. 其他细节调整
- **铁范**: 尺寸略微缩小（0.5×0.4×0.4 → 0.45×0.35×0.38）
- **整体风格**: 减少过度细节，追求古籍插图的简洁美感
