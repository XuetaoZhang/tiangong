# 3D建模改进记录

## 已完成的修正 (2026-06-28)

### 1. 水碓 (Shuidui) ✅

#### 主要改进：
- **凸轮机构改进**：将原来的半圆柱凸轮改为更符合《天工开物》原图的**拐木结构**（横向突出的木棒）
- **运动逻辑优化**：改进了碓杆的起落运动，拐木在下方转到时推起碓杆尾部，更符合实际物理原理
- **受拨块调整**：碓杆尾部的受拨块向下延伸，便于拐木推动

#### 技术细节：
```javascript
// 拐木结构：主体木棒 + 根部加厚 + 木销锁死
- 拐木主体：0.16×0.44×0.16 的方木，向-Y方向突出
- 3根拐木错120°相位分布
- 运动：拐木在下方(π到2π区间)时产生推力
```

#### 验证要点：
- [ ] 拐木旋转时是否正确推起碓杆
- [ ] 3个碓杆是否错开舂击（120°相位）
- [ ] 碓杵落下速度是否自然

### 2. 鼓风炉 (Gufeng) ✅

#### 主要改进：
- **炉体结构优化**：改用圆柱+圆台分段组合，替代球体压扁，形成真实的腰鼓形
  - 炉下段（0.3-0.8m）：圆柱形炉身
  - 炉中段（0.8-1.4m）：腰鼓形最宽处
  - 炉上段（1.4-2.0m）：收口段
- **炉缸补充**：新增炉底积聚铜液的炉缸区域（内凹标记）
- **风箱改进**：增加双向活塞结构的细节
  - 前后端板显示阀门位置
  - 活塞板标记
  - 改进的送风管（锥形）
  - 双立柱支架
- **多风口系统**：实现对称送风布局
  - 主风口（对准风箱）
  - 对称副风口（另一侧）
  - 炉底风沟 + 木制盖板

#### 技术细节：
```javascript
// 炉体尺寸：
- 炉底半径：0.7
- 炉腰半径：0.82（最宽处）
- 炉顶半径：0.5（收口）
- 总高度：2.0

// 风箱结构：
- 箱体：1.0×0.5×0.5
- 活塞板：0.42×0.42
- 前后阀门标记：直径0.08
```

#### 验证要点：
- [ ] 炉体腰鼓形是否明显
- [ ] 风箱活塞推拉动作是否可见
- [ ] 风口布局是否合理
- [ ] 炉内火光效果是否协调

### 3. 纺织机 (Fangzhi) ✅

#### 主要改进：
- **衢盘衢脚系统重构**：真实表现花本程序控制结构
  - 衢盘：12组线团（提花程序载体），每组包含线团+轴
  - 衢脚：36根下垂牵引线（每组3根），模拟1800根的密集感
  - 底部连接横木（连接综片）
- **综片结构完善**：从2片改为4片，增加框架细节
  - 每片综框有上下横木、左右竖木的完整框架
  - 综丝增加到15根/片
  - 4片综框对应4个踏板，实现复杂提花
- **经线密度提升**：从18根增加到48根，更真实地表现织布密度
- **筘的细节化**：从简单方块改为密集细条结构
  - 筘框 + 30根筘齿
- **梭子改进**：增加流线型船形设计
  - 主体 + 前后尖角
  - 内部纬线管可见
- **踏板系统**：从2个改为4个，对应4片综框

#### 技术细节：
```javascript
// 衢盘衢脚：
- 线团：12组，间距0.095
- 衢脚：36根（3根/组），直径0.004
- 连接横木：宽度towerW+0.1

// 综片：
- 4片，z位置：-0.25, -0.08, 0.08, 0.25
- 每片框架：上横木(粗) + 下横木 + 左右竖木
- 综丝：15根/片，间距0.065

// 经线：
- 48根，间距0.0185
- 直径：0.002

// 筘齿：
- 30根，间距0.03
- 尺寸：0.03×0.18×0.008
```

#### 验证要点：
- [ ] 衢脚线束是否密集下垂
- [ ] 综片框架是否清晰可见
- [ ] 4个踏板与4片综框对应关系
- [ ] 经线密度是否合理
- [ ] 梭子流线型是否明显
- [ ] 筘齿是否呈密集条状

## 改进原则

所有改进遵循以下原则：

1. **忠于原典**：以《天工开物》明崇祯十年刊本原版插图为依据
2. **物理准确**：机械运动符合物理原理，力学关系合理
3. **结构完整**：关键部件结构完整，不过度简化
4. **适度细化**：在性能允许范围内提高细节，但避免过度复杂
5. **保持风格**：木料质感、尺寸比例保持一致
