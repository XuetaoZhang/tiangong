# 天工开物 · 3D 书

> 让明代《天工开物》的古代工程智慧在指尖活起来 —— 一个可交互的 3D 线装古籍 Web 应用。
>

## 项目简介

本项目将明崇祯十年（1637年）涂绍煃刊本《天工开物》转化为可翻阅、可交互的 3D 线装古籍。用户从封面"开启阅读"，3D 线装本翻开放大过渡到目录页，点击篇目进入正文：左页为竖排古文原文（含译文悬浮），右页为古籍原版木刻插图，点击古画即可唤起依据原画复原的 3D 器物模型悬浮于书页之上，支持拖拽旋转、缩放、点击热点联动古文。

## 功能特性

- **3D 线装本翻书动画**：封面 → 目录 → 正文三页统一书本模型（书脊缝隙、打开角度、4 个线装孔、立体书脊立柱、书页层叠厚度），封面翻开放大无缝过渡到目录页
- **古籍原版插图**：正文右页采用明崇祯十年刊本原版木刻插图（来源：法国国家图书馆藏本 / 书格 shuge.org，CC BY 4.0），非 AI 生成
- **古文原文 + 译文**：左页竖排古文，悬停显示白话译文，点击古文段联动 3D 部件高亮
- **3D 器物复原**：依据古籍原画 + 现代复原图程序化建模，6 个器物（筒车、龙骨水车、水碓、纺织机、鼓风炉、墨）
- **点击古画唤起 3D**：未揭示时古画悬停发光 + 提示文字，点击触发书本后靠 + 模型淡入动画（1.2s）
- **热点交互**：3D 模型上可点击热点，联动古文滚动与部件释义
- **三档释义**：每个部件提供小学生 / 标准 / 专家三档释义
- **模拟参数**：可调节水流速度 / 踩踏速度等参数驱动 3D 动画

## 技术栈

- **React 18** + **Vite 5** — 前端框架与构建
- **@react-three/fiber** + **@react-three/drei** + **Three.js** — 3D 渲染
- **Zustand** — 全局状态管理

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（默认端口 5180，--strictPort 锁定）
npm run dev

# 生产构建
npm run build

# 预览构建产物
npm run preview
```

打开浏览器访问 `http://localhost:5180/`

## 设计理念

- **古籍美学**：米黄宣纸书页 (#F4ECD8)、墨色文字、线装孔、书脊厚度、14 层书页层叠
- **传统竖排**：右页目录、左页古文均采用竖排右起阅读顺序
- **木材质感**：3D 模型统一木纹材质（metalness: 0.0, roughness: 0.78）+ 软接触阴影
- **无割裂过渡**：封面翻开 → 放大 → 淡出 → 目录淡入，全程无黑屏跳转
